Alzheimer's Disease Data Analysis

Exploratory Data Analysis | R, RStudio, ggplot2

Project Overview

This project explores the relationships between demographic characteristics, lifestyle behaviors, clinical measurements, and Alzheimer's disease diagnoses through exploratory data analysis (EDA).

The goal is to identify patterns and potential risk factors associated with Alzheimer's disease while demonstrating practical skills in data cleaning, statistical analysis, and data visualization using R.

Dataset (from kaggle) 

The analysis examines a dataset containing 2,149 patient records and 35 variables, including:

Demographics: Age, gender, ethnicity, and education level

Lifestyle Factors: BMI, smoking, alcohol consumption, physical activity, diet quality, and sleep quality

Medical History: Diabetes, hypertension, cardiovascular disease, and family history

Clinical Measurements: Blood pressure, cholesterol levels, and cognitive assessments

Target Variable: Alzheimer's disease diagnosis
